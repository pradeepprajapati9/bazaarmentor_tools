# BazaarMentor

Business software and automation for small businesses — billing, stock, khata, WhatsApp automation and custom scripts.

Static site: HTML + Bootstrap 5 (CDN) with a small theme layer of its own. No build step, no framework.

| File | Page |
| --- | --- |
| `index.html` | Home |
| `services.html` | Services |
| `work.html` | Shipped work |
| `about.html` | About |
| `contact.html` | Contact + FAQ |
| `assets/style.css` | Dark gold theme, animations |
| `assets/main.js` | Scroll reveals, counters, WhatsApp enquiry form |

Live at https://pradeepprajapati9.github.io/bazaarmentor_tools/ (GitHub Pages, `main` branch, `/` root).

**Setup note:** the WhatsApp number is a placeholder. Replace `91XXXXXXXXXX` in `assets/main.js`.
